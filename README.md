# 透视训练 · Perspective Trainer

一个纯前端的单页应用（SPA），通过随机生成的 3D 透视场景，帮助你训练空间想象力和透视直觉。无需后端，打开 `index.html` 即可游玩。

## ✨ 功能特性

- 🎲 **随机关卡**：每关随机生成相机参数（视场角、方位角、仰角、横滚角），带来丰富多变的透视视角。
- 📐 **两种关卡类型**：
  - **找地平线**：在透视下的立方体上，点击两点确定地平线位置。
  - **补全缺角**：立方体缺失一个顶点（及其相连的棱和面填充），点击猜测该顶点的位置。
- 🧠 **难度自适应**：立方体在屏幕中的占比自动适配，确保始终清晰可辨。
- 🛠 **辅助工具**（默认关闭，可自由开关）：
  - **棱延长线**：显示所有可见棱的延长线，帮助理解消失点与地平线的关系。
  - **地面网格**：在方块底部平面绘制网格，帮助推断缺失顶点的空间位置。
- 📊 **即时反馈**：提交后立即显示判定结果、偏差数值以及正确答案的视觉标注。
- 🌓 **暗色主题**：护眼的深色界面，专注于几何线条。
- 📱 **响应式**：适配桌面与移动端。
- ⌨️ **键盘快捷键**：回车提交/下一关，`E` 切换棱延长线，`G` 切换地面网格，`Esc` / `R` 清空当前点击。

## 🎮 玩法说明

### 关卡类型一：找地平线

- 屏幕中央会出现一个透视下的立方体。
- 你的任务：**点击两个点**，用它们定义一条直线，代表你猜测的**地平线**。
- 提交后，系统会比较你画的线与真实地平线的：
  - **角度偏差**（单位：度）
  - **位置偏差**（单位：像素）
- 两项都在容差范围内即判定通过。

> 💡 小提示：开启「棱延长线」工具，观察所有棱的延长线交汇处，那里就是消失点，地平线正是穿过消失点的水平线。

### 关卡类型二：补全缺角

- 屏幕上的立方体会**缺少一个顶点**，与该顶点相连的 3 条棱以及包含该顶点的面填充都会被移除。
- 你的任务：**点击一次**，猜测缺失顶点的位置。
- 提交后，系统会计算你点击的位置与真实顶点投影位置的**像素距离**，小于容差即通过。
- 答案展示时，会用虚线从真实顶点连接到它的 3 个邻居，补全立方体轮廓。

> 💡 小提示：开启「地面网格」工具，观察立方体底边与网格的关系，利用透视规律推断缺失顶点的位置。

## 🛠 辅助工具

工具栏位于顶栏右侧，**默认全部关闭**，可随时点击切换。设置会跨关卡保留。

| 工具 | 适用关卡 | 说明 |
|------|----------|------|
| `↗ 棱延长线` | 找地平线 | 将所有可见棱在屏幕空间延长，显示透视方向与消失点。 |
| `▦ 地面网格` | 补全缺角 | 在方块底部平面绘制 6×6 网格，辅助判断空间位置。 |

**快捷键**：
- `E` — 切换棱延长线
- `G` — 切换地面网格

## 🧱 技术实现

- **纯原生 JavaScript**，无任何框架、无依赖。
- **Canvas 2D** 渲染，所有 3D 投影为手动实现。
- **相机模型**：基于视场角、方位角、仰角、横滚角构建视图矩阵，透视投影。
- **可见性判断**：通过相机位置与面所在半空间的关系，正确剔除背面。
- **地平线计算**：由相机基向量推导世界水平面（y=0）的消隐线。
- **线段裁剪**：`projectSegment()` 处理穿过相机后方的线段（用于地面网格）。
- **响应式**：`resize` 时自动调整相机距离，使立方体始终保持合适大小。

## 🔧 自定义与配置

如果你希望调整难度或视觉效果，可以在 `index.html` 中找到以下常量：

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `TOL.horizon.angle` | `5.0` | 地平线关卡允许的角度偏差（度） |
| `TOL.horizon.distRatio` | `0.035` | 地平线关卡允许的位置偏差（相对画面高度） |
| `TOL.complete.distRatio` | `0.085` | 补全关卡允许的位置偏差（相对画面高度） |
| `HS` | `0.5` | 立方体半边长 |
| `TARGET_FRAC` | `0.60` | 立方体在屏幕中的目标占比 |
| `randomParams()` | — | 控制相机参数的随机范围 |

例如，将 `TOL.complete.distRatio` 改为 `0.05` 会使补全关卡更难。
